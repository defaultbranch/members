This project provides a web application. Main IOs are:
- database backend (RDBMS)
- web frontend (HTML)

The web frontend supports usability on mobile devices with small screens as well as on laptops or PCs with large screens.

This application is a club software, allowing for member and guest management.

Main use cases will be, initially:
- keep a list of members
- allow members to authenticate using TOTP (RFC 6238)
- schedule regular club meetings (training hours)
- track presence at regular club meetings (training hours)
- provide contact data, mostly for emergency during trainings
- keep a list of guests (trial lessons)
- schedule irregular meetings (club assembly, board meetings, open events)
- keep a list of guests (open events)
- keep payment status (money due, payments received)
